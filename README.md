# Diana Sedal — сайт-портфолио веб-разработчика

Многостраничный сайт-портфолио с собственным бэкендом: заявки с формы сохраняются в базу данных, приходят в Telegram и на почту, а просматривать их можно в закрытой админ-панели.

**Сайт:** [diana-web.onrender.com](https://diana-web.onrender.com)

## Что умеет сайт

**Форма заявки с полным циклом обработки**
- Проверка полей в браузере и на сервере.
- Обязательное согласие на обработку персональных данных: без него сервер не примет заявку.
- Заявка сохраняется в PostgreSQL.
- Мгновенное уведомление в Telegram через бота.
- Копия заявки на почту через Gmail (Nodemailer), можно сразу ответить клиенту.

**Админ-панель**
- Вход по паролю, сессия хранится в защищённой cookie (`httpOnly`, `secure` на продакшене).
- Список всех заявок с датой, контактами и пожеланиями.
- Удаление заявок.

**Два языка: русский и английский**
- Переключатель RU / EN без перезагрузки страницы.
- Выбранный язык запоминается в браузере.
- Переводятся тексты, заголовки вкладок и подписи для экранных читалок.

**Адаптивная вёрстка**
- Корректно отображается на компьютере, планшете и телефоне.
- Отдельная раскладка первого экрана для мобильных, бургер-меню.
- Галерея работ с просмотром скриншотов в увеличенном виде.

**Аналитика и юридическая часть**
- Яндекс Метрика с Вебвизором и картой кликов.
- Сайт добавлен в Яндекс Вебмастер для индексации в поиске.
- Страница политики конфиденциальности, описывающая сбор данных, cookies и Метрику.

## Страницы

- **Главная:** первый экран, обо мне, услуги, превью работ, частые вопросы, форма заявки.
- **Портфолио:** четыре проекта со скриншотами и ссылками на живые сайты.
- **Контакты:** почта, WhatsApp, Telegram и форма заявки.
- **Политика конфиденциальности.**
- **Админ-панель** (закрытая).

## Безопасность

- Пароли и ключи не хранятся в коде: они передаются через переменные окружения (`.env` локально и Environment на Render).
- SQL-запросы с параметрами (`$1, $2…`) защищают от SQL-инъекций.
- Сервер сам проверяет обязательные поля и согласие, не полагаясь только на браузер.

## Как запустить у себя

1. Установите Node.js и PostgreSQL.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Установите зависимости и запустите сервер:

```bash
npm install
npm start
```

4. Откройте [http://localhost:3000](http://localhost:3000). Таблица для заявок создастся автоматически при первом запуске.
