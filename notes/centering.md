 **что** выравниваю и **внутри какого родителя** это лежит.

## 1. Текст или одна кнопка внутри обычного блока (`p`, `div`, `h2`)

Родитель — обычный блок. Не flex, не grid.

Используйте:

```css
text-align: center;
```

**Ваш случай** (кнопка «Свяжитесь со мной» внутри `<p>`):

```html
<p style="margin-top: 36px; text-align: center;">
  <a class="btn">Свяжитесь со мной</a>
</p>
```

`justify-content` здесь не сработает: у `<p>` нет `display: flex`.

---

## 2. Несколько кнопок / иконок в ряд, ровно по центру

Родитель должен стать flex:

```css
display: flex;
justify-content: center; /* по горизонтали */
align-items: center;     /* по вертикали, если есть высота */
gap: 12px;               /* расстояние между детьми */
```

Без `display: flex` свойство `justify-content` браузер просто игнорирует.

То же самое для сетки:

```css
display: grid;
justify-content: center; /* или place-items: center; */
```

---

## 3. Весь блок по центру страницы (сам блок уже на всю ширину)

`text-align` двигает **содержимое внутри**, а не сам блок.

Если элемент широкий (`width: 100%`), он уже занимает всю строку — «центрировать блок» бессмысленно. Центрируют то, что **уже́же** родителя:

```css
width: 200px;
margin-left: auto;
margin-right: auto;
```

Для flex-ребёнка:

```css
margin-inline: auto;
/* или у родителя: justify-content: center */
```

---

## 4. Картинка по центру

Картинка по умолчанию ведёт себя как текст (inline). Два рабочих варианта:

```css
/* на родителе */
text-align: center;

/* или сделать картинку блоком */
img {
  display: block;
  margin-left: auto;
  margin-right: auto;
}
```

---

## Шпаргалка «почему не работает»

| Написали | Почему пусто |
|---|---|
| `justify-content` на `p` / `div` без flex | Это не flex-контейнер |
| `text-align` на самой кнопке | Выравнивает текст **внутри** кнопки, а не саму кнопку |
| `margin: auto` у кнопки-ссылки | У `a` часто `display: inline` / `inline-flex`, `auto`-поля по бокам не центрируют |
| `align-items` без высоты родителя | По вертикали «центр» некуда ставить |

---

## Что выбрать за 5 секунд

1. Одна кнопка / строка текста в `p` или `div` → **`text-align: center`** на родителе.
2. Несколько элементов в ряд → **`display: flex` + `justify-content: center`** на родителе.
3. Узкий блок внутри широкой колонки → **`margin-left: auto; margin-right: auto`**.
4. По вертикали внутри высокой коробки → flex на родителе и **`align-items: center`**.

Инлайн-стиль в HTML годится, чтобы быстро проверить в инспекторе. Когда заработало — перенесите правило в `css/style.css` и уберите `style="..."` из HTML.
